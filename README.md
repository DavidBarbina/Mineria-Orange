# Orange.

### Se busca realizar un caso aplicativo sobre metodología de Ciencia de Datos.

### Se explican las diferencias de trabajar un proyecto de manera tradicional vs realizarlo de manera ágil. Además se ejemplifican mediante un caso hipotético de un proyecto de Ciencia de Datos.

### Se consideran los datos del archivo csv de pacientes, todos ellos con la misma enfermedad. Durante su tratamiento, cada paciente ha respondido a uno de los 5 medicamentos, el fármaco A, el fármaco B, el fármaco C (de proveedor nacional), el fármaco X y el Y (de proveedor extranjero).

## Se elabora un reporte detallado que muestra los hallazgos obtenidos con la finalidad de encontrar el modelo que hace la mejor predicción de todos los que se encuentran disponibles en Orange.
